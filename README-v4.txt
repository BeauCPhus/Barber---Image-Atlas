BARBER MOTION ATLAS v4 — PILOT CLASSIFICATION LAYER

v3 remains the archival baseline: Barber's plate metadata and source-faithful descriptions are unchanged.

v4 adds atlas-tags.json, a separate interpretive design index. The pilot contains 50 deliberately varied mechanisms. Search now includes:
- motion (rotation, translation, oscillation, compound paths, etc.)
- purpose (self-return, clear obstruction, vary travel, reverse at endpoints, etc.)
- behavior/constraint (moving pivot, cam constrained, link constrained, over-center, etc.)

Use the “Motion-tagged” chip to show only plates represented in the pilot set.

This pilot is intentionally small. Its purpose is to test whether the vocabulary is useful in real design browsing before expanding classification across the full book.
