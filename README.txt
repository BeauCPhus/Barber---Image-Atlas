BARBER MOTION ATLAS v2

Open index.html for the 156-plate browser.

New in v2:
- Search plate, section, category, part and printed page.
- "Sync Gutenberg descriptions" imports Barber's numbered descriptions directly from the Project Gutenberg HTML and caches them in the browser's localStorage.
- After sync, search includes mechanism numbers and full descriptions.
- Matching description appears on search-result cards.
- Plate detail shows all cached Barber description blocks associated with that plate.
- Previous/next plate navigation retained.

For the Gutenberg sync feature, host this folder on GitHub Pages (recommended). The static plate/category browser works without the sync.

Source: Project Gutenberg eBook #58391, Thomas Walter Barber, The Engineer's Sketch-Book (4th ed., 1902).
